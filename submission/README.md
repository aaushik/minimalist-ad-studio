# Minimalist Ad Studio — submission pack

This folder maps one-to-one to the four deliverables in the assignment brief.
The live product is the fastest place to start.

- **Live app:** <https://nudge-new-assignment.vercel.app>
- **Public repository:** <https://github.com/aaushik/minimalist-ad-studio>
- **Assignment brief:** [source copy](../docs/ASSIGNMENT_BRIEF.md)

## Deliverable checklist

| Brief requirement | Submission artifact |
| --- | --- |
| 1. Working app | [App link, evaluator flow and local setup](01-working-app/README.md) |
| 2. Build record | [Repo history, tooling, app prompts and raw transcripts](02-build-record/README.md) |
| 3. One-page decision doc | [Rules, cuts and least-certain decision](03-one-page-decision-doc.md) |
| 4. Top three production failure modes | [Harms, mitigations and launch timing](04-failure-modes.md) |

The evidence behind the scoring standard is indexed in
[supporting evidence](05-supporting-evidence/README.md). It is kept separate
from the one-page document so that the decision summary stays within the
brief's hard limit.

## Suggested review order

1. Open the live app and generate the default Vitamin B5 ad.
2. Select **Send to scorer** and inspect the three scores and action lines.
3. Upload an unrelated static ad in **Scorer** to test the independent path.
4. Read the one-page decision document, then the failure modes.
5. Use the build record and raw transcripts to inspect the process and
   iterations in full.
