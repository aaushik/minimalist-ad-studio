# Current ads corpus

This directory contains current Minimalist advertising evidence separately from
brand-positioning pages, product pages, packaging, and editorial content.

The collection target is **all verifiable unique creatives we can reasonably
discover**. Twenty static concepts and twenty text concepts are minimum
coverage checks, not maximum sample sizes.

## Structure

- `static/` — canonical static creative images and their manifest.
- `text/` — canonical text-ad records and their manifest.
- `excluded-variants/` — retrieved files excluded from the unique count, kept
  for auditability.

Nothing in this directory is automatically treated as a brand rule. Once the
corpus has adequate coverage, current practice will be compared with the
brand's declared principles in a separate analysis.
